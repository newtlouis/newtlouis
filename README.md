### Two repositories worth opening

atelier (https://github.com/newtlouis/atelier) turns a free-text customer request into a priced, traceable, auditable quote. The model reads text. It never decides a price. Structured output with a versioned schema, business validation after the call, indirect prompt injection treated as the default case, and every call costed and timed. Symfony 7.4, PHP 8.4, PHPStan level 10, mutation score 100%.

setting-engine (https://github.com/newtlouis/setting-engine) runs three autonomous agents coordinated through a shared database, with no queue and no central scheduler. Hybrid retrieval over a knowledge base and past conversations, with a tuned similarity threshold. Replies are scored by a second model against an explicit rubric, not judged by eye. Node.js, SQLite, Playwright.
